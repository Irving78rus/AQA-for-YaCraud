📌 **О проекте**

Демо проект предназначеный для демонстрации подхода к проектированию автотестов

🎯 **Цели проекта**

Построение архитектуры тестов.
Проверка ключевого пользовательского сценария: авторизация
Реализация позитивных и негативных тест-кейсов

🏗 **Архитектура проекта**

Проект построен с использованием следующих подходов:

🔹 **Page Object Model (POM)**

Вся логика взаимодействия со страницами вынесена в отдельные классы (pages/), что:
уменьшает дублирование кода
упрощает поддержку
изолирует UI-логику от тестов

🔹 **Fixtures (фикстуры)**

Расширение стандартного test из Playwright:
подготовка тестового окружения
создание и передача Page Object в тесты

🔹 **Разделение слоёв**

Проект разделён на логические части:
tests/      # тесты
pages/      # Page Objects
fixtures/   # фикстуры
data/       # тестовые данные
utils/      # вспомогательные функции
constants/  # константы и маршруты

🔹 **Конфигурация Playwright**

В playwright.config.js реализованы:
baseURL — единая точка входа
retries — повтор тестов при падении
trace — запись шагов при ошибках
screenshot / video — артефакты для анализа падений
